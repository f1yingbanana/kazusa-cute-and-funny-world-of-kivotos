# North Moat Boathouse Loft

Up a ladder in the old [[wildhunt_boathouse|boathouse]]: a folding catapult,
order crates labelled in code and a map of the fortress walls with drop points
marked in pencil. The window looks straight over the wall. It is padlocked, and
dusty everywhere except where people actually work.

## Whose it is

This is where the [[free_trade_cartel]] sends goods over the wall:
[[fuyu-wakasa|Fuyu]]'s catapult throws parcels onto quiet corners of the
[[wildhunt_rampart|rampart]], following drop points [[miyo-sakurai|Miyo]] has
planned.
