# Hackers' Lounge

The [[veritas]] den in the [[millennium_clubhouse|clubhouse]]: server racks
along one wall, a bank of screens, a projector for movie nights, and an air
conditioner turned so low that a luxury camping tent has been pitched in the
back to keep warm in. Empty energy-drink cans form a slow sculpture by the bin.

## The door

The door code changes weekly and is never written down.
