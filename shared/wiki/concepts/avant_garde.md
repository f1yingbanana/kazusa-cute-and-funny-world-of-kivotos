# Avant-Garde

Avant-Garde is a large autonomous machine built by
[[rio-tsukatsuki|Rio Tsukatsuki]]. It appeared at Eridu during the conflict
over [[aris-tendou|Aris]] and the [[game_development_department]], described
in [[game_development_department_crisis]]. Millennium's engineers later went
to work on the machine themselves.
